入门

Greenshot 在后台运行。它的图标位于时钟旁边，即任务栏的通知区域中。 用鼠标右键单击它，即可打开包含所有抓图方式、设置...和本帮助的菜单。

看不到图标？Windows 11 可能把它隐藏在箭头（^）后面。自助服务 中的 您的设置 可以帮您把它显示在时钟旁边，并检查 Print Screen 键是否能到达 Greenshot。

截取屏幕

使用快捷键或从 Greenshot 图标的菜单开始抓图：

抓取窗口Alt + Print Screen立即抓取当前活动窗口。启用采用交互式抓图（“抓图”选项卡）后，改为在抓图界面中选择窗口。
抓取全屏Ctrl + Print Screen立即抓取屏幕。如果有多台显示器，图标菜单会提供所有显示器或其中一台。

菜单中还有从窗口列表中选择抓取（无需抓图界面即可抓取您选择的已打开窗口）、 从文件载入图片和打开上次保存位置。 您可以在设置的“常规”选项卡中更改快捷键。

抓图界面

Greenshot 会拍下所有显示器的画面，并将其显示在最上层。选择期间画面不会变化， 因此打开的菜单或工具提示会保持原样。只有您选择的部分会被抓取。Esc 关闭抓图界面，不抓取任何内容。

在画面上方您会看到：

  • 带有尺寸的选区，
  • 放大镜，位于鼠标旁边，显示每个像素，方便您精确放置角点，
  • 四角的面板：按键（F1）、信息（I）和选区的预览（P）。 它们会自动避开您的操作位置。

选择时按 F1：按键面板始终列出当前可用的按键。 Greenshot 会记住您隐藏了某个面板，按 F1 或 I 可以重新显示。

区域、窗口、固定尺寸和文字

  • 区域：用鼠标拖出一个矩形，松开即抓取。使用键盘时：方向键移动鼠标， Enter 开始选择，再按一次 Enter 抓取。按住 Shift 可只改变宽度或只改变高度。
  • 窗口（空格）：选中鼠标下方的窗口，单击或按 Enter 抓取。 Greenshot 会选择最内层的部分，例如工具栏；将鼠标移到窗口的外边缘即可选择整个窗口。 Tab 和 Shift + Tab 选择下一个或上一个窗口。
  • 固定尺寸（F）：一个精确尺寸的矩形（例如 1280 × 720）跟随鼠标移动。1 – 9、0 选择尺寸， C 切换鼠标所在的角，按住 Alt 可放置矩形而不吸附到窗口。您自己的尺寸在 “抓图”选项卡中设置，最近几次抓图的尺寸也会提供。
  • 文字（T）：Greenshot 使用 Windows 的文字识别读取屏幕上的文字，并为每一行加上框。 单击某一行，或在文字上拖动，即可抓取它们。要以文本形式获取文字，请将抓图发送到 Windows OCR， 它会把文字复制到剪贴板。这需要在 Windows 中安装识别语言；语言在 “抓图”选项卡的 文字识别 (OCR) 中选择。

安装二维码插件后，Greenshot 会找到屏幕上的二维码并为其加上框。单击二维码可复制其内容或打开其网址。

不冻结屏幕进行选择

在“抓图”选项卡中关闭 选择时冻结屏幕，或在选择时按 L，即可在实时屏幕上选择：视频会继续播放，抓图在您完成选择时进行。 文字模式和预览需要冻结的画面。打开的菜单通常在您单击时就会关闭，因此请使用冻结的屏幕来抓取菜单。

某些内容要过一会儿才出现？请在“抓图”选项卡中设置 在抓图前等待时间（毫秒），或在实时屏幕上选择。

截图的去向

抓图后，Greenshot 会把截图发送到您的目标。默认情况下，它每次都会用一个小菜单询问您。 菜单中的每个目标都有一个固定的带下划线字母，例如 C 表示剪贴板，S 表示保存，因此您可以用键盘选择。 请在“抓图后的动作”选项卡中，或在图标菜单的快速设定中选择目标。

  • 用图片编辑器打开：先为截图添加标注，请参阅图片编辑器。
  • 直接保存而不询问使用“输出”选项卡中的文件夹和文件名模式，另存到会询问这些信息。
  • 复制图片到剪贴板、打印图片、使用E-Mail发送、Windows share 和 Windows OCR（复制截图中的文字）。
  • 插件会添加更多目标，例如 Microsoft Word、Excel、PowerPoint、Outlook 和 OneNote、PDF、Box、Dropbox、Jira 和 Confluence。 它们在“插件”选项卡中设置，您也可以在那里关闭某个插件。

“抓图后的动作”选项卡中的 可用 列可在所有地方关闭某个目标。 抓图后收到哪些通知，请在“抓图”选项卡的 通知 中设置。

图片编辑器

编辑器可以在截图上添加形状、文字、箭头、高亮等内容，或者隐藏不应被他人看到的内容。 除了您的抓图，它还可以打开文件或剪贴板中的图片（图标菜单）。 您绘制的所有内容都保持为元素，可以选择、移动、更改或删除。

标签页

一个编辑器窗口以标签页显示多张图片，新的抓图会作为标签页在您最后使用的编辑器窗口中打开。 Ctrl + Tab 切换到下一个标签页，Ctrl + W 关闭一个标签页。将标签页拖到另一个编辑器窗口， 或用鼠标右键单击它，将其移到新窗口。标签栏上的 + 会新建一张空白图片。 关闭含有未保存图片的窗口时，Greenshot 只询问一次：全部保存、全部放弃 或取消。 更喜欢每次抓图一个窗口？请在“编辑器”选项卡中关闭标签页。

高亮和遮盖

像画矩形一样画出高亮（H）或遮盖（O）区域，然后在工具栏中选择模式：

  • 高亮文字像荧光笔一样为区域着色，高亮区域使其他部分变暗并模糊， 灰阶使其他部分变为灰色，放大放大该区域。
  • 马赛克效果或模糊效果可隐藏密码、姓名、账号或面孔。

裁剪

选择裁剪工具（C），画出要保留的区域，Enter 确认，Esc 取消。 再按一次 C，或使用工具栏中的 裁剪模式，即可切换模式：

  • 垂直裁除 或 水平裁除 从图片中删除一条区域并将其余部分拼接起来，例如去掉长页面中间的空白部分。 裁切边缘 选择接缝的样式：直线、锯齿、波浪、撕裂或无缝。
  • 自动裁剪去除图片四周单一颜色的边框。

添加图片和重复使用元素

  • 将图片文件拖到编辑器中，或用 Ctrl + V 粘贴图片。编辑菜单中的插图窗口会添加另一个已打开窗口的抓图。
  • 在多张截图中使用相同的元素：物件菜单中的保存物件到文件，然后在下一张截图中使用从文件载入物件。
  • 保存为 .greenshot 文件，可使所有元素保持可编辑，以便以后继续。

自动步骤和配方

配方会自动处理您的抓图，例如为每张抓图添加边框，或一次完成保存和上传。 图标菜单中的快速设定 > 自动步骤 可开启或关闭预设步骤， 更多… 在“配方”选项卡中打开它们的设置。 图标的配方菜单可启动您的配方，并打开 配方管理器 和 Recipe Editor。 配方随 Recipe Editor 插件提供。

设置

使用图标菜单中的设置...或下面的链接打开设置。

  • 常规：语言、颜色（浅色、深色或跟随 Windows）、图标大小、 开机时自动启动 Greenshot、快捷键、代理以及 Greenshot 检查更新的频率。
  • 抓图：抓取鼠标指针、相机快门声、放大镜、冻结屏幕、 通知、抓图前的等待时间、您的固定尺寸、交互式窗口抓图以及文字识别的语言。
  • 输出：保存的文件夹和文件名模式（单击 ? 查看占位符， 例如 ${YYYY}-${MM}-${DD} 或 ${title}；模式中的 \ 会创建文件夹）、图片格式和 JPEG 质量。
  • 抓图后的动作：抓图后执行的操作，请参阅截图的去向。
  • 编辑器：标签页、编辑器窗口的大小、关闭时是否询问保存，以及新图片的大小和颜色。
  • 打印机：使图片适合页面、旋转或居中、以彩色、灰阶或反色打印，以及带日期和时间的页脚。
  • 插件：开启、关闭和配置插件。更改在下次启动 Greenshot 时生效。
  • 专家设置：用于特殊情况的设置，例如远程桌面、DirectX 抓图（HDR 屏幕需要）、内存和速度， 以及剪贴板格式。只有在了解其作用时才更改它们。

Greenshot 将设置保存在 %APPDATA%\Greenshot 中的 greenshot.ini 里（便携版将其保存在 Greenshot.exe 旁边）。 自助服务 中的 文件和配置 会显示它的位置。

遇到问题时

自助服务 会检查 Greenshot 并解决大多数问题。请通过图标菜单中的关于 Greenshot，然后单击 自助服务 打开它， 或者直接转到相应的部分：

  • Print Screen 没有反应或打开了其他程序：快捷键和冲突 会显示 OneDrive 或截图工具是否占用了该键，并将其交还给 Greenshot。
  • 找不到截图：文件和配置 会显示 Greenshot 将它们保存在哪里。
  • 复制到剪贴板失败：剪贴板诊断 会找出占用剪贴板的程序。
  • Greenshot 崩溃或更新后缺少插件：安装完整性 会检查已安装的文件。
  • 报告问题：系统和硬件 中的 复制系统信息 和 日志中的错误可以帮助我们帮助您。请在 github.com/greenshot/greenshot/issues 报告问题。
