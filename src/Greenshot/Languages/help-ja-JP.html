Greenshot ヘルプ

設定を開く のように greenshot: で始まるリンクは、Greenshot のその画面を開きます。 インストーラーで Greenshot をインストールした場合に使えます。ポータブル版や Greenshot Light では使えません。 Greenshot を開く前に、ブラウザーが確認を求める場合があります。

はじめに

Greenshot はバックグラウンドで動作します。アイコンはタスク バーの通知領域、時計の隣にあります。 アイコンを右クリックすると、すべてのキャプチャ、設定... とこのヘルプがあるメニューが開きます。

アイコンが見つかりませんか? Windows 11 では矢印 (^) の中に隠れていることがあります。セルフサービス の セットアップ でアイコンを時計の隣に表示できます。また、Print キーが Greenshot に届いているかも確認できます。

キャプチャはホットキー、または Greenshot アイコンのメニューから始めます:

メニューには、キャプチャ画面を使わずに選んだウィンドウをキャプチャする リストから選択して "ウィンドウ キャプチャ"、 ファイルからイメージを開く...、最後に保存した場所を開く もあります。 ホットキーは 設定の一般タブ で変更できます。

キャプチャ画面

Greenshot はすべてのモニターの画像を撮り、すべての上に表示します。選択中は何も変わらないので、開いているメニューやツールチップもそのまま残ります。 キャプチャされるのは選択した部分だけです。Esc を押すと、何もキャプチャせずにキャプチャ画面を閉じます。

画像の上には次のものが表示されます:

  • サイズ付きの選択範囲、
  • ズーム: マウスの隣に表示され、1 ピクセルずつ見える拡大鏡です。角を正確に合わせられます。
  • 四隅のパネル: キー (F1)、情報 (I)、選択範囲のプレビュー (P)。 パネルは邪魔にならないよう自動で移動します。

選択中に F1 を押してください。キー パネルには、その時点で使えるキーが常に表示されます。 パネルを隠すと Greenshot はそれを覚えます。F1 または I で再び表示できます。

範囲、ウィンドウ、固定サイズ、テキスト

  • 範囲: マウスで四角形をドラッグし、ボタンを離すとキャプチャします。キーボードでは、矢印キーでマウスを動かし、 Enter で選択を開始、もう一度 Enter でキャプチャします。Shift を押したままにすると、幅だけ、または高さだけを変更できます。
  • ウィンドウ (Space): マウスの下のウィンドウが選択され、クリックまたは Enter でキャプチャします。 Greenshot は一番内側の部分 (例: ツール バー) を選択します。ウィンドウ全体を選択するには、ウィンドウの外枠にマウスを動かします。 Tab と Shift + Tab で次または前のウィンドウを選択します。
  • 固定サイズ (F): 1280 × 720 などの決まったサイズの四角形がマウスについて動きます。1 – 9 でサイズを選び、 C でマウスが持つ角を変えます。Alt を押したままにすると、ウィンドウに吸着せずに配置できます。独自のサイズは キャプチャ タブ で設定します。最近のキャプチャのサイズも候補に表示されます。
  • テキスト (T): Greenshot は Windows の文字認識で画面上のテキストを読み取り、各行を枠で囲みます。 行をクリックするか、単語の上をドラッグしてキャプチャします。単語をテキストとして取得するには、キャプチャを Windows OCR に送ります。 テキストがクリップボードにコピーされます。Windows に認識用の言語がインストールされている必要があります。言語は キャプチャ タブ の 文字認識 (OCR) で選びます。

QR コード プラグインを使うと、Greenshot は画面上の QR コードを見つけて枠で囲みます。クリックすると内容をコピーするか、その Web アドレスを開きます。

画面を止めずに選択する

キャプチャ タブ で 選択中は画面を静止 をオフにするか、選択中に L を押すと、ライブ画面の上で選択できます。動画は再生され続け、選択を終えた時点でキャプチャされます。 テキスト モードとプレビューには止めた画像が必要です。開いたメニューはクリックすると閉じることが多いので、メニューには止めた画面を使ってください。

少し経ってから表示されるものがありますか? キャプチャ タブ で ミリ秒待機してからキャプチャ を設定するか、ライブ画面で選択してください。

スクリーンショットの出力先

キャプチャの後、Greenshot はスクリーンショットを出力先に送ります。既定では、毎回小さなメニューで尋ねます。 そこにある出力先にはそれぞれ決まった下線付きの文字があり (例: クリップボードは C、保存は S)、キーボードで選べます。 出力先は 出力先タブ、またはアイコンのメニューの クィック設定 で選びます。

  • イメージ エディターで開く: まずスクリーンショットに注釈を付けます。イメージ エディター を参照してください。
  • 保存 (下欄の設定を使用) は 出力タブ のフォルダーとファイル名パターンを使います。名前を付けて保存 (ダイアログを表示) はそれらを尋ねます。
  • クリップボードにコピー、プリンターに送る、メール、Windows share、Windows OCR (スクリーンショットのテキストをコピー)。
  • プラグインで出力先が増えます。例: Microsoft Word、Excel、PowerPoint、Outlook、OneNote、PDF、Box、Dropbox、Jira、Confluence。 設定は プラグイン タブ で行い、そこでプラグインをオフにすることもできます。

出力先タブ の 利用可能 列で、出力先をすべての場所でオフにできます。 キャプチャ後にどの通知を受け取るかは、キャプチャ タブ の 通知 で設定します。

イメージ エディター

エディターでは、スクリーンショットに図形、テキスト、矢印、ハイライトなどを追加したり、他の人に見せたくないものを隠したりできます。 キャプチャのほか、ファイルやクリップボードの画像も開けます (アイコンのメニュー)。 描いたものはすべて要素のまま残り、選択、移動、変更、削除ができます。

タブ

エディター ウィンドウは複数の画像をタブで表示します。新しいキャプチャは、最後に使ったエディター ウィンドウのタブとして開きます。 Ctrl + Tab で次のタブへ移動し、Ctrl + W でタブを閉じます。タブを別のエディター ウィンドウにドラッグするか、 右クリックして新しいウィンドウに移動できます。タブ バーの + で新しい空の画像を作ります。 保存していない画像があるウィンドウを閉じると、Greenshot は一度だけ尋ねます: すべて保存、すべて破棄、またはキャンセル。 キャプチャごとに 1 つのウィンドウが良いですか? エディター タブ でタブをオフにしてください。

描画ツール

エディターの左側、オブジェクト メニュー、またはキーでツールを選び、画像の上でドラッグします。 上部のツール バーには、ツールまたは選択した要素のオプション (線の色、塗りつぶしの色、太さなど) が表示されます。

E楕円M絵文字
L直線Hハイライト

  • 描画中に Shift を押したままにすると正方形や円、または 15° 刻みの線になります。サイズ変更中は縦横比を保ちます。 Ctrl を押したままにすると中心から描画またはサイズ変更します。何かを楕円で囲むときに便利です。
  • テキスト: テキスト ボックスを描いて入力します。テキストをダブルクリックすると変更でき、Enter で確定、Shift + Enter で改行します。
  • 選択した要素: 矢印キーで移動 (Shift と一緒に 10 ピクセル)、Ctrl + 矢印キーでサイズ変更、 Page Up / Page Down で 1 つ上または下の階層へ、Delete で削除、Ctrl + D で複製します。 Shift を押しながらクリックすると、複数の要素を選択できます。
  • Ctrl + Z で元に戻し、Ctrl + Y でやり直します。

ハイライトと難読化

ハイライト (H) または難読化 (O) の範囲を四角形のように描き、ツール バーでモードを選びます:

  • テキスト ハイライト は蛍光ペンのように範囲に色を付け、範囲ハイライト はそれ以外を暗くぼかします。 グレースケール はそれ以外を灰色にし、拡大 は範囲を大きくします。
  • モザイク または ぼかし で、パスワード、名前、口座番号、顔を隠します。

トリミング

トリミング ツール (C) を選び、残す範囲を描きます。Enter で確定、Esc で取り消します。 もう一度 C を押すか、ツール バーの トリミング モード でモードを切り替えます:

  • 垂直方向に切り抜き または 水平方向に切り抜き は画像から帯状の部分を取り除き、残りをつなげます。例えば長いページの 空いた中央部分を省くときに使います。切り取り端 でつなぎ目の見た目を選びます: 直線、ジグザグ、波、破れ、つなぎ目なし。
  • 自動トリミング は画像の周りの単色の枠を取り除きます。

画像の追加と要素の再利用

  • 画像ファイルをエディターにドラッグするか、Ctrl + V で画像を貼り付けます。編集 メニューの ウィンドウ キャプチャを貼り付け で、開いている別のウィンドウのキャプチャを追加します。
  • 同じ要素を多くのスクリーンショットで使う: オブジェクト メニューの オブジェクトをファイルに保存... で保存し、次のスクリーンショットで ファイルからオブジェクトを読み込み... を使います。
  • .greenshot ファイルとして保存すると、すべての要素が編集可能なまま残り、後で続きができます。

ファイル メニューと上部のツール バーには、プラグインのものも含め、すべての出力先が表示されます。 保存後、下部のステータス バーを右クリックすると、ファイルのパスをコピーしたり、そのフォルダーを開いたりできます。

自動ステップとレシピ

レシピはキャプチャに対する処理を自動で行います。例えば、すべてのキャプチャに枠線を付けたり、保存とアップロードを一度に行ったりします。 アイコンのメニューの クィック設定 > 自動ステップ で用意されたステップをオンまたはオフにし、 その他… で レシピ タブ にあるその設定を開きます。 アイコンの レシピ メニューから自分のレシピを開始したり、レシピ マネージャー と Recipe Editor を開いたりできます。 レシピは Recipe Editor プラグインに含まれています。

設定

設定は、アイコンのメニューの 設定...、または次のリンクで開きます。

  • 一般: 言語、配色 (ライト、ダーク、Windows に合わせる)、アイコンのサイズ、 Greenshot を Windows のスタートアップに登録、ホットキー、プロキシ、更新を確認する頻度。
  • キャプチャ: マウス ポインターのキャプチャ、カメラの音、拡大鏡、画面の停止、 通知、キャプチャ前の待機、固定サイズ、対話型のウィンドウ キャプチャ、文字認識の言語。
  • 出力: 保存先のフォルダーとファイル名パターン (? をクリックするとプレースホルダーが表示されます。 例: ${YYYY}-${MM}-${DD} や ${title}。パターン内の \ はフォルダーを作ります)、画像形式、JPEG の品質。
  • 出力先: キャプチャ後の動作。スクリーンショットの出力先 を参照してください。
  • エディター: タブ、エディター ウィンドウのサイズ、閉じるときの保存の確認、新しい画像のサイズと色。
  • プリンター: 画像をページに合わせる、回転や中央揃え、カラー、グレースケール、反転での印刷、日時入りのフッター。
  • プラグイン: プラグインのオンとオフ、および設定。変更は Greenshot の次回起動時に反映されます。
  • 高度な設定: 特別な場合の設定。例: リモート デスクトップ、DirectX キャプチャ (HDR 画面に必要)、メモリと速度、 クリップボードの形式。何をするか分かっている場合にだけ変更してください。

Greenshot は設定を %APPDATA%\Greenshot の greenshot.ini に保存します (ポータブル版は Greenshot.exe の隣に保存します)。 セルフサービス の ファイルと構成 で場所を確認できます。

うまく動かないとき

セルフサービス は Greenshot を確認し、ほとんどの問題を解決します。アイコンのメニューの Greenshot について から セルフサービス を開くか、 該当するセクションに直接移動してください:

  • Print を押しても何も起きない、または別のものが開く: ホット キーと競合 で OneDrive や Snipping Tool がキーを使っていないかを確認し、キーを Greenshot に戻します。
  • スクリーンショットが見つからない: ファイルと構成 で Greenshot の保存先を確認できます。
  • クリップボードへのコピーに失敗する: クリップボードの診断 でクリップボードをふさいでいるプログラムを見つけます。
  • 更新後に Greenshot が異常終了する、またはプラグインがない: インストールの整合性 でインストールされたファイルを確認します。
  • 問題を報告する: システムとハードウェア の システム情報をコピー と ログのエラー があると、私たちがあなたを助けやすくなります。問題は github.com/greenshot/greenshot/issues に報告してください。
