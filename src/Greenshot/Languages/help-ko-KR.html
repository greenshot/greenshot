Greenshot 도움말

설정 열기처럼 greenshot:으로 시작하는 링크는 Greenshot의 해당 창을 엽니다. 설치 프로그램으로 설치한 Greenshot에서만 동작하며, 포터블 버전과 Greenshot Light에서는 동작하지 않습니다. 브라우저는 Greenshot을 열기 전에 확인을 요청합니다.

시작하기

Greenshot은 백그라운드에서 실행됩니다. 아이콘은 작업 표시줄 알림 영역의 시계 옆에 있습니다. 마우스 오른쪽 버튼으로 클릭하면 모든 캡처, 설정..., 이 도움말이 있는 메뉴가 열립니다.

아이콘이 보이지 않나요? Windows 11은 아이콘을 화살표(^) 뒤에 숨길 수 있습니다. Self-Service의 Your setup은 아이콘을 시계 옆에 표시해 주고, Print Screen 키가 Greenshot에 전달되는지도 확인합니다.

캡처 화면

Greenshot은 모든 모니터의 사진을 찍어 모든 창 위에 보여 줍니다. 선택하는 동안에는 아무것도 바뀌지 않으므로 열린 메뉴나 도구 설명이 그대로 남아 있습니다. 선택한 부분만 캡처됩니다. Esc는 아무것도 캡처하지 않고 캡처 화면을 닫습니다.

사진 위에는 다음이 보입니다:

  • 크기가 표시된 선택 영역,
  • 마우스 옆의 돋보기인 확대경: 픽셀 하나하나를 보여 주어 모서리를 정확히 맞출 수 있습니다,
  • 모서리의 패널: 키(F1), 정보(I), 선택 영역의 미리 보기(P). 패널은 방해가 되지 않도록 스스로 비켜 줍니다.

선택 중에 F1을 누르세요. 키 패널은 그 순간 쓸 수 있는 키를 항상 보여 줍니다. 패널을 숨기면 Greenshot이 기억하며, F1이나 I로 다시 표시합니다.

구역, 창, 고정 크기, 텍스트

  • 구역: 마우스로 사각형을 드래그하고, 버튼을 놓으면 캡처됩니다. 키보드로는 화살표 키가 마우스를 움직이고, Enter로 선택을 시작하고 다시 Enter로 캡처합니다. 너비나 높이만 바꾸려면 Shift를 누르고 있으세요.
  • 창(Space): 마우스 아래의 창이 선택되고, 클릭이나 Enter로 캡처합니다. Greenshot은 가장 안쪽 부분(예: 도구 모음)을 선택합니다. 창 전체를 선택하려면 창의 바깥 가장자리로 이동하세요. Tab과 Shift + Tab은 다음 창 또는 이전 창을 선택합니다.
  • 고정 크기(F): 정확한 크기(예: 1280 × 720)의 사각형이 마우스를 따라다닙니다. 1 – 9로 크기를 고르고, C로 마우스가 잡는 모서리를 바꾸며, Alt를 누르고 있으면 창에 맞춰지지 않고 자유롭게 놓입니다. 자신만의 크기는 캡처 탭에서 정하며, 최근 캡처의 크기도 함께 제공됩니다.
  • 텍스트(T): Greenshot이 Windows 텍스트 인식으로 화면의 텍스트를 읽고 줄마다 테두리를 그립니다. 줄을 클릭하거나 단어 위로 드래그해서 캡처합니다. 단어를 텍스트로 얻으려면 캡처를 Windows OCR로 보내세요. 텍스트가 클립보드에 복사됩니다. Windows에 인식 언어가 설치되어 있어야 하며, 언어는 캡처 탭의 Text recognition (OCR)에서 고릅니다.

QR 코드 플러그인이 있으면 Greenshot이 화면의 QR 코드를 찾아 테두리를 그립니다. 코드를 클릭하면 내용을 복사하거나 웹 주소를 열 수 있습니다.

화면을 멈추지 않고 선택하기

캡처 탭에서 Freeze the screen while selecting을 끄거나 선택 중에 L을 누르면 실시간 화면에서 선택합니다. 동영상은 계속 재생되고, 선택을 마치는 순간 캡처됩니다. 텍스트 모드와 미리 보기에는 멈춘 사진이 필요합니다. 열린 메뉴는 클릭하면 대개 닫히므로 메뉴는 멈춘 화면에서 캡처하세요.

잠시 뒤에야 나타나는 것이 있나요? 캡처 탭에서 캡처 전 밀리초 지연(1000밀리초 = 1초)을 설정하거나 실시간 화면에서 선택하세요.

스크린샷을 보내는 곳

캡처가 끝나면 Greenshot은 스크린샷을 지정한 대상으로 보냅니다. 기본적으로 매번 작은 메뉴로 묻습니다. 메뉴의 각 대상에는 고정된 밑줄 문자가 있어(예: 클립보드는 C, 저장은 S) 키보드로 고를 수 있습니다. 대상은 파일 저장 방법 탭이나 아이콘 메뉴의 빠른 설정에서 고릅니다.

  • 이미지 편집기에서 열기: 먼저 스크린샷에 주석을 답니다. 이미지 편집기를 보세요.
  • 직접 저장은 출력 파일 설정 탭의 폴더와 파일 이름 패턴을 사용하고, 다른 이름으로 저장은 이를 묻습니다.
  • 클립보드로 복사, 인쇄기로 보내기, 이메일, Windows share, Windows OCR(스크린샷의 텍스트를 복사).
  • 플러그인은 Microsoft Word, Excel, PowerPoint, Outlook, OneNote, PDF, Box, Dropbox, Jira, Confluence 같은 대상을 추가합니다. 플러그인 탭에서 설정하며, 플러그인을 끌 수도 있습니다.

파일 저장 방법 탭의 Available 열은 대상을 모든 곳에서 끕니다. 캡처 후 받을 알림은 캡처 탭의 Notifications에서 정합니다.

이미지 편집기

편집기는 스크린샷에 도형, 텍스트, 화살표, 강조 등을 넣거나 다른 사람이 보면 안 되는 것을 가립니다. 캡처뿐 아니라 파일이나 클립보드의 이미지도 엽니다(아이콘 메뉴). 그린 것은 모두 선택, 이동, 변경, 삭제할 수 있는 요소로 남습니다.

탭

편집기 창 하나에 여러 이미지가 탭으로 표시되며, 새 캡처는 마지막으로 사용한 편집기 창에 탭으로 열립니다. Ctrl + Tab은 다음 탭으로, Ctrl + W는 탭을 닫습니다. 탭을 다른 편집기 창으로 드래그하거나, 마우스 오른쪽 버튼으로 클릭해 새 창으로 옮길 수 있습니다. 탭 줄의 +는 비어 있는 새 이미지를 만듭니다. 저장하지 않은 이미지가 있는 창을 닫으면 Greenshot이 한 번만 묻습니다: Save all, Discard all 또는 취소. 캡처마다 창 하나가 좋다면 편집기 탭에서 탭을 끄세요.

그리기 도구

편집기 왼쪽, 객체 메뉴 또는 키로 도구를 고른 다음 이미지 위에서 드래그합니다. 위쪽 도구 모음에는 도구나 선택한 요소의 옵션(선 색, 채우기 색, 두께 등)이 표시됩니다.

  • 텍스트: 텍스트 상자를 그리고 입력합니다. 텍스트를 두 번 클릭하면 수정하고, Enter로 마치며, Shift + Enter로 줄을 바꿉니다.

  • Ctrl + Z는 실행 취소, Ctrl + Y는 다시 실행입니다.

강조와 가리기

강조(H)나 가리기(O) 영역을 사각형처럼 그리고 도구 모음에서 모드를 고릅니다:

  • 문자열 강조는 형광펜처럼 영역에 색을 칠하고, 구역 강조는 나머지를 어둡고 흐리게 하며, 그레이스케일은 나머지를 회색으로 만들고, 확대는 영역을 크게 보여 줍니다.
  • 픽셀라이즈나 흐림은 비밀번호, 이름, 계좌 번호, 얼굴을 가립니다.

잘라내기

잘라내기 도구(C)를 고르고 남길 영역을 그립니다. Enter로 확인하고 Esc로 취소합니다. C를 다시 누르거나 도구 모음의 Crop mode로 모드를 바꿉니다:

  • Crop out vertically 또는 Crop out horizontally는 이미지에서 띠 하나를 잘라 내고 나머지를 이어 붙입니다. 예를 들어 긴 페이지의 빈 가운데를 뺄 때 씁니다. Cut edges는 이음매 모양(직선, 지그재그, 물결, 찢김, 이음매 없음)을 고릅니다.
  • 자동 잘라내기는 이미지 둘레의 단색 테두리를 없앱니다.

이미지 추가와 요소 재사용

  • 이미지 파일을 편집기로 드래그하거나 Ctrl + V로 이미지를 붙여 넣습니다. 편집 메뉴의 작업 화면 삽입은 다른 열린 창의 캡처를 추가합니다.
  • 여러 스크린샷에 같은 요소 쓰기: 객체 메뉴의 객체를 파일로 저장, 다음 스크린샷에서 파일로부터 객체 읽어오기.
  • .greenshot 파일로 저장하면 모든 요소를 수정할 수 있는 상태로 두고 나중에 계속할 수 있습니다.

자동 단계와 레시피

레시피는 캡처에 자동으로 작업을 합니다. 예를 들어 모든 캡처에 테두리를 넣거나, 한 번에 저장하고 업로드합니다. 아이콘 메뉴의 빠른 설정 > Automatic steps는 준비된 단계를 켜거나 끄고, More…는 Recipes 탭에서 그 설정을 엽니다. 아이콘의 레시피 메뉴는 레시피를 실행하고 Recipe Manager와 Recipe Editor를 엽니다. 레시피는 Recipe Editor 플러그인과 함께 제공됩니다.

설정

아이콘 메뉴의 설정...이나 아래 링크로 설정을 엽니다.

  • 일반: 언어, 색(밝게, 어둡게, Windows와 같게), 아이콘 크기, 윈도우 구동시 Greenshot 실행, 단축키, 프록시, 업데이트 확인 주기.
  • 캡처: 마우스 포인터 캡처, 카메라 소리, 돋보기, 화면 멈추기, 알림, 캡처 전 대기, 고정 크기, 대화형 창 캡처, 텍스트 인식 언어.
  • 출력 파일 설정: 저장 폴더와 파일 이름 패턴(?를 클릭하면 자리 표시자를 볼 수 있습니다. 예: ${YYYY}-${MM}-${DD}, ${title}. 패턴의 \는 폴더를 만듭니다), 이미지 형식, JPEG 품질.
  • 파일 저장 방법: 캡처 후에 일어날 일. 스크린샷을 보내는 곳을 보세요.
  • 편집기: 탭, 편집기 창 크기, 닫을 때 저장 여부 질문, 새 이미지의 크기와 색.
  • 인쇄기: 이미지를 페이지에 맞추기, 회전 또는 가운데 정렬, 컬러·그레이스케일·반전 인쇄, 날짜와 시간이 있는 바닥글.
  • 플러그인: 플러그인을 켜고 끄고 설정합니다. 변경 사항은 Greenshot을 다음에 시작할 때 적용됩니다.
  • 고급: 원격 데스크톱, DirectX 캡처(HDR 화면에 필요), 메모리와 속도, 클립보드 형식 같은 특수한 경우를 위한 설정. 무엇을 하는지 알 때만 바꾸세요.

Greenshot은 설정을 %APPDATA%\Greenshot의 greenshot.ini에 저장합니다(포터블 버전은 Greenshot.exe 옆). Self-Service의 Files & Configuration에서 위치를 볼 수 있습니다.

문제가 생겼을 때

Self-Service는 Greenshot을 점검하고 대부분의 문제를 해결합니다. 아이콘 메뉴의 Greenshot 소개에서 Self-Service를 누르거나, 알맞은 항목으로 바로 가세요:

  • Print Screen이 아무 동작도 하지 않거나 다른 것을 엽니다: Hotkeys & Conflicts는 OneDrive나 캡처 도구가 키를 가져갔는지 보여 주고, 키를 Greenshot에 돌려줍니다.
  • 스크린샷을 찾을 수 없습니다: Files & Configuration이 Greenshot의 저장 위치를 보여 줍니다.
  • 클립보드 복사가 실패합니다: Clipboard Diagnostics가 클립보드를 막는 프로그램을 찾습니다.
  • 업데이트 후 Greenshot이 멈추거나 플러그인이 없습니다: Installation Integrity가 설치된 파일을 확인합니다.
  • 문제 보고: System & Hardware의 Copy System Info와 로그의 오류가 도움이 됩니다. 문제는 github.com/greenshot/greenshot/issues에 보고해 주세요.
