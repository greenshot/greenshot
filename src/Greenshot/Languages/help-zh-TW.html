入門

Greenshot 在背景執行。它的圖示位於時鐘旁邊，也就是工作列的通知區域。 用滑鼠右鍵按一下圖示，即可開啟包含所有擷取方式、喜好設定...和本說明的選單。

看不到圖示？Windows 11 可能把它藏在箭頭（^）後面。自助服務 中的 您的設定 可以幫您把它顯示在時鐘旁邊，並檢查 Print Screen 鍵是否能傳到 Greenshot。

使用快速鍵或從 Greenshot 圖示的選單開始擷取：

選單中還有從清單擷取視窗（不經過擷取畫面，直接擷取您挑選的已開啟視窗）、 從檔案開啟圖片和開啟上次擷取位置。 您可以在設定的「一般」索引標籤中變更快速鍵。

擷取畫面

Greenshot 會拍下所有顯示器的畫面，並顯示在最上層。選取期間畫面不會改變， 因此開啟的選單或工具提示會保持原樣。只有您選取的部分會被擷取。Esc 會關閉擷取畫面，不擷取任何內容。

在畫面上方您會看到：

  • 附有大小的選取範圍，
  • 放大鏡，位於滑鼠旁邊，顯示每個像素，方便您精確放置角落，
  • 四個角落的面板：按鍵（F1）、資訊（I）和選取範圍的預覽（P）。 它們會自動避開您正在操作的位置。

選取時按 F1：按鍵面板一律列出當下可用的按鍵。 Greenshot 會記住您隱藏了哪個面板，按 F1 或 I 可以再次顯示。

區域、視窗、固定大小和文字

  • 區域：用滑鼠拖曳出一個矩形，放開即擷取。使用鍵盤時：方向鍵移動滑鼠， Enter 開始選取，再按一次 Enter 擷取。按住 Shift 可只變更寬度或只變更高度。
  • 視窗（空白鍵）：選取滑鼠下方的視窗，按一下或按 Enter 擷取。 Greenshot 會選取最內層的部分，例如工具列；將滑鼠移到視窗的外框即可選取整個視窗。 Tab 和 Shift + Tab 選取下一個或上一個視窗。
  • 固定大小（F）：一個精確大小的矩形（例如 1280 × 720）會跟著滑鼠移動。1 – 9、0 選擇大小， C 切換滑鼠所在的角落，按住 Alt 可放置矩形而不貼齊視窗。您自己的大小在 「擷取」索引標籤中設定，最近幾次擷取的大小也會列出。
  • 文字（T）：Greenshot 使用 Windows 的文字辨識讀取螢幕上的文字，並為每一行加上外框。 按一下某一行，或在文字上拖曳，即可擷取。若要以文字形式取得內容，請將擷取的畫面傳送到 Windows OCR， 它會把文字複製到剪貼簿。這需要在 Windows 中安裝辨識語言；語言在 「擷取」索引標籤的 文字識別 (OCR) 中選擇。

安裝 QR 碼外掛程式後，Greenshot 會找出螢幕上的 QR 碼並加上外框。按一下 QR 碼可複製其內容或開啟其網址。

不凍結螢幕進行選取

在「擷取」索引標籤中關閉 選擇時凍結螢幕，或在選取時按 L，即可在即時螢幕上選取：影片會繼續播放，擷取會在您完成選取時進行。 文字模式和預覽需要凍結的畫面。開啟的選單通常在您按一下時就會關閉，因此擷取選單時請使用凍結的螢幕。

某些內容要過一會兒才會出現？請在「擷取」索引標籤中設定 擷取之前等待的時間 (毫秒)，或在即時螢幕上選取。

螢幕擷圖的去處

擷取後，Greenshot 會將螢幕擷圖傳送到您的目的地。預設情況下，每次都會用一個小選單詢問您。 選單中的每個目的地都有固定的底線字母，例如 C 代表剪貼簿，S 代表儲存，因此您可以用鍵盤選擇。 請在「目的地」索引標籤中，或在圖示選單的快速喜好設定中選擇目的地。

  • 在圖片編輯器開啟：先為螢幕擷圖加上註解，請參閱圖片編輯器。
  • 直接儲存 (使用以下設定)使用「輸出」索引標籤中的資料夾和檔名格式，另存新檔 (顯示對話方塊)會詢問這些資訊。
  • 複製到剪貼簿、傳送到印表機、電子郵件、Windows share 和 Windows OCR（複製螢幕擷圖中的文字）。
  • 外掛程式會加入更多目的地，例如 Microsoft Word、Excel、PowerPoint、Outlook 和 OneNote、PDF、Box、Dropbox、Jira 和 Confluence。 它們在「外掛程式」索引標籤中設定，您也可以在那裡關閉某個外掛程式。

「目的地」索引標籤中的 可用 欄可在所有地方關閉某個目的地。 擷取後要收到哪些通知，請在「擷取」索引標籤的 通知 中設定。

圖片編輯器

編輯器可以在螢幕擷圖上加入圖形、文字、箭頭、標示等內容，或隱藏不該讓別人看到的內容。 除了您擷取的畫面，它也能開啟檔案或剪貼簿中的圖片（圖示選單）。 您繪製的所有內容都會保持為元素，可以選取、移動、變更或移除。

索引標籤

一個編輯器視窗會以索引標籤顯示多張圖片，新的擷取會以索引標籤的形式在您最後使用的編輯器視窗中開啟。 Ctrl + Tab 切換到下一個索引標籤，Ctrl + W 關閉一個索引標籤。將索引標籤拖曳到另一個編輯器視窗， 或用滑鼠右鍵按一下它，將它移到新視窗。索引標籤列上的 + 會建立一張新的空白圖片。 關閉含有未儲存圖片的視窗時，Greenshot 只會詢問一次：全部儲存、全部放棄 或取消。 偏好每次擷取一個視窗？請在「編輯器」索引標籤中關閉索引標籤。

標示和模糊處理

像畫矩形一樣畫出標示（H）或模糊處理（O）的區域，然後在工具列中選擇模式：

  • 標示文字像螢光筆一樣為區域上色，標示區域讓其他部分變暗並模糊， 灰階讓其他部分變成灰色，放大放大該區域。
  • 像素化或模糊可隱藏密碼、姓名、帳號或臉孔。

裁剪

選擇裁剪工具（C），畫出要保留的區域，Enter 確認，Esc 取消。 再按一次 C，或使用工具列中的 裁剪模式，即可切換模式：

  • 垂直裁除 或 水平裁除 會從圖片中移除一條區域並接合其餘部分，例如省略長頁面中間的空白部分。 裁切邊緣 選擇接縫的樣式：直線、鋸齒、波浪、撕裂或無縫。
  • 自動裁剪會移除圖片四周單一色彩的邊框。

加入圖片和重複使用元素

  • 將圖片檔拖曳到編輯器中，或用 Ctrl + V 貼上圖片。編輯選單中的插入視窗會加入另一個已開啟視窗的擷取畫面。
  • 在多張螢幕擷圖上使用相同的元素：使用物件選單中的儲存物件到檔案，然後在下一張螢幕擷圖上使用從檔案載入物件。
  • 儲存為 .greenshot 檔案，可讓所有元素保持可編輯，以便日後繼續。

自動步驟和配方

配方會自動處理您擷取的畫面，例如為每次擷取加上框線，或一次完成儲存和上傳。 圖示選單中的快速喜好設定 > 自動步驟 可開啟或關閉預設的步驟， 更多… 會在「配方」索引標籤中開啟它們的設定。 圖示的配方選單可啟動您的配方，並開啟 配方管理器 和 Recipe Editor。 配方隨 Recipe Editor 外掛程式提供。

設定

使用圖示選單中的喜好設定...或下方的連結開啟設定。

  • 一般：語言、色彩（淺色、深色或跟隨 Windows）、圖示大小、 開機啟動 Greenshot、快速鍵、Proxy 以及 Greenshot 檢查更新的頻率。
  • 擷取：擷取滑鼠指標、相機快門聲、放大鏡、凍結螢幕、 通知、擷取前的等待時間、您的固定大小、互動式視窗擷取，以及文字辨識的語言。
  • 輸出：儲存的資料夾和檔名格式（按一下 ? 查看預留位置， 例如 ${YYYY}-${MM}-${DD} 或 ${title}；格式中的 \ 會建立資料夾）、圖片格式和 JPEG 品質。
  • 目的地：擷取後要做什麼，請參閱螢幕擷圖的去處。
  • 編輯器：索引標籤、編輯器視窗的大小、關閉時是否詢問儲存，以及新圖片的大小和色彩。
  • 印表機：讓圖片符合頁面、旋轉或置中、以彩色、灰階或反轉色彩列印，以及含日期和時間的頁尾。
  • 外掛程式：開啟、關閉和設定外掛程式。變更會在下次啟動 Greenshot 時生效。
  • 專家：用於特殊情況的設定，例如遠端桌面、DirectX 擷取（HDR 螢幕需要）、記憶體和速度， 以及剪貼簿格式。只有在了解其作用時才變更。

Greenshot 將設定保存在 %APPDATA%\Greenshot 中的 greenshot.ini（可攜版則保存在 Greenshot.exe 旁邊）。 自助服務 中的 檔案和組態 會顯示它的位置。

遇到問題時

自助服務 會檢查 Greenshot 並修正大多數問題。請從圖示選單中的關於 Greenshot 開啟，然後按一下 自助服務， 或直接前往對應的區段：

  • Print Screen 沒有反應或開啟了其他程式：熱鍵和衝突 會顯示 OneDrive 或剪取工具是否佔用了該鍵，並將它交還給 Greenshot。
  • 找不到螢幕擷圖：檔案和組態 會顯示 Greenshot 將它們儲存在哪裡。
  • 複製到剪貼簿失敗：剪貼簿診斷 會找出佔用剪貼簿的程式。
  • Greenshot 當機或更新後缺少外掛程式：安裝完整性 會檢查已安裝的檔案。
  • 回報問題：系統和硬體 中的 複製系統資訊 和 記錄檔中的錯誤能幫助我們協助您。請在 github.com/greenshot/greenshot/issues 回報問題。
