Bdu

Greenshot yetteddu deg ugilal. Tignit-is tella ɣer tama n temrilt, deg temnaḍt n yilɣa n ufeggag n twuri. Sit fell-as s tqeffalt tayeffust n tɣerdayt akken ad teldiḍ umuɣ s akk tuṭṭfiwin, Ismenyifen... d tallelt-a.

Ur d-tettbin ara tignit? Windows 11 yezmer ad tt-yeffer deffir n tneccabt (^). Tawila-inek deg Tallalt tudmawant ad tt-id-yesken ɣer tama n temrilt, yerna ad isenqed ma tasarut Print Screen tewweḍ ɣer Greenshot.

Agdil n tuṭṭfa

Greenshot yeṭṭef tugna n akk igdilen-ik, yerna yesskan-itt nnig kullec. Ulac ayen ara ibeddlen mi ara tferneḍ, ihi umuɣ yeldin neɣ tawennaḍt ad qqimen deg wadeg-nsen. D ayen kan i tferneḍ ara yettwaṭṭfen. Esc yemdel agdil n tuṭṭfa war ma yeṭṭef kra.

Nnig tugna ad twaliḍ:

  • afran s teɣzi-ines,
  • asemɣer ɣer tama n tɣerdayt, i d-yesskanen yal tiqqeḍt, akken ad tesbeddeḍ tiɣmert s telqay,
  • igalisen deg tɣemrin: tisura (F1), talɣut (I) d teskant n ufran (P). Ttinigen weḥd-sen akken ur k-ttḥesbun ara.

Sit ɣef F1 mi ara tferneḍ: agalis n tsura yesskan yal tikkelt tisura i yeddan deg tallit-nni. Greenshot yettmekti mi ara teffreḍ agalis, F1 neɣ I ad t-id-yerr.

Tamnaṭ, asfaylu, teɣzi yettwasbadun d uḍris

  • Tamnaṭ: zuɣer asrem s tɣerdayt, mi ara tserrḥeḍ ad yettwaṭṭef. S unasiw: tineccabin ssenkadent taɣerdayt, Enter yebda afran, Enter tikkelt nniḍen yeṭṭef-it. Ṭṭef Shift akken ad tbeddleḍ kan tehri neɣ kan teɣzi.
  • Asfaylu (Space): asfaylu yellan ddaw n tɣerdayt yettwafren, asiti neɣ Enter yeṭṭef-it. Greenshot yefren aḥric akk agensan, am ufeggag n yifecka; ssenkez taɣerdayt ɣer yiri aberrani n usfaylu akken ad tferneḍ asfaylu akk. Tab d Shift + Tab fernen asfaylu d-iteddun neɣ win yezrin.
  • Teɣzi yettwasbadun (F): asrem s teɣzi tusdidt, am 1280 × 720, iḍefren taɣerdayt. 1 – 9, 0 fernen teɣzi, C ibeddel tiɣmert i teṭṭef tɣerdayt, ṭṭef Alt akken ad t-tesbeddeḍ war ma yenṭeḍ ɣer yisfuyla. Tiɣzi-inek ttwasbadent deg iccer Tuṭṭfa, tiɣzi n tuṭṭfiwin tineggura ttwasumrent daɣen.
  • Aḍris (T): Greenshot yeqqar aḍris yellan deg ugdil s usentem n uḍris n Windows, yerna yezzi kra n yal izirig. Sit ɣef yizirig neɣ zuɣer ɣef yimawalen akken ad ten-tṭṭfeḍ. Akken ad tawiḍ imawalen d aḍris, azen tuṭṭfa ɣer Windows OCR, i yessenɣalen aḍris ɣef afus. Ilaq ad tebded tutlayt n usentem deg Windows; tutlayt tettwafren deg iccer Tuṭṭfa, Tikci n uḍris (OCR).

S usiɣzef n tengalin QR, Greenshot yettaf tingalin QR deg ugdil yerna yezzi-asent. Sit ɣef yiwet akken ad tneɣleḍ agbur-is neɣ ad teldiḍ tansa-ines web.

Afran war ma yesgumed ugdil

Sens Skeref agdil deg ufran deg iccer Tuṭṭfa, neɣ sit ɣef L mi ara tferneḍ, ad tferneḍ ɣef ugdil udrir: tavidyut ad tkemmel tturar, tuṭṭfa ad tettwag mi ara tfakkeḍ afran. Askar n uḍris d teskant ḥwaǧen tugna yesgumden. Umuɣen yeldin ttmedlen s umata mi ara tsiteḍ, ihi seqdec agdil yesgumden i nutni.

Kra ur d-yettbin ara alamma yezri kra n wakud? Sbadu Millitasinin n uraǧu send tuṭṭfa deg iccer Tuṭṭfa, neɣ fren ɣef ugdil udrir.

Anida ara tedduṭ tuṭṭfa

Deffir n tuṭṭfa, Greenshot yettazen tuṭṭfa ɣer tniɣriwin-ik. S wudem amezwer, yesteqsay yal tikkelt s wumuɣ amecṭuḥ. Yal taniɣert dinna ɣur-s asekkil yettwaderren ur nbeddel ara, am C i ɣef afus d S i usekles, ihi tzemreḍ ad tt-tferneḍ s unasiw. Fren tiniɣriwin deg iccer Taniɣert n tuṭṭfa n ugdil, neɣ deg Ismenyifen iruraden deg wumuɣ n tignit.

  • Ldi deg umaẓrag n tugniwin: rnu tizmilin ɣef tuṭṭfa di tazwara, wali amaẓrag n tugniwin.
  • Sekles s srid (s useqdec n iɣewwaṛen daw-a) yesseqdac akaram d tneɣruft n yisem n ufaylu n iccer Tuffɣa, Sekles s yisem (sken asfaylu n udiwenni) yesteqsay fell-asen.
  • Ɣef afus, Ar tsaggazt, Imayl, Windows share d Windows OCR (yessenɣal aḍris n tuṭṭfa).
  • Isiɣzaf rennun tiniɣriwin nniḍen, am Microsoft Word, Excel, PowerPoint, Outlook d OneNote, PDF, Box, Dropbox, Jira d Confluence. Ttwasbadun deg iccer Isiɣzaf, anda tzemreḍ daɣen ad tsenseḍ asiɣzef.

Tagejdit Yella n iccer Taniɣert n tuṭṭfa n ugdil tessens taniɣert anda yebɣu yili. Ilɣa ara d-tawiḍ deffir n tuṭṭfa ttwasbadun deg iccer Tuṭṭfa, Ilɣa.

Amaẓrag n tugniwin

Amaẓrag yettarnu talɣiwin, aḍris, tineccabin, asebrureq d wayen nniḍen ɣef tuṭṭfa, neɣ yeffer ayen ur ilaq ara ad t-walin wiyaḍ. Ɣer tama n tuṭṭfiwin-ik, yeldi tugniwin seg ufaylu neɣ seg ɣef afus (umuɣ n tignit). Kra n wayen i tsunɣeḍ yeqqim d aferdis i tzemreḍ ad tferneḍ, ad tsenkzeḍ, ad tbeddleḍ neɣ ad tekkseḍ.

Iccaren

Asfaylu n umaẓrag yesskan aṭas n tugniwin d iccaren, tuṭṭfa tamaynut teldi d iccer deg usfaylu n umaẓrag i tesseqdceḍ taneggarut. Ctrl + Tab iddu ɣer yiccer d-iteddun, Ctrl + W yemdel iccer. Zuɣer iccer ɣer usfaylu nniḍen n umaẓrag, neɣ sit fell-as s tqeffalt tayeffust akken ad t-tesnekzeḍ ɣer usfaylu amaynut. + deg ufeggag n yiccaren yebda tugna tamaynut, tilemt. Mi ara tmedleḍ asfaylu s tugniwin ur nettwasekles ara, Greenshot yesteqsay tikkelt kan: Sekles akk, Sefsex akk neɣ sefsex. Tebɣiḍ yiwen usfaylu i yal tuṭṭfa? Sens iccaren deg iccer Amaẓrag.

Ifecka n usuneɣ

Fren afecku deg tama tazelmaḍt n umaẓrag, deg wumuɣ Taɣawsa neɣ s tsarut-is, sakin zuɣer ɣef tugna. Afeggag n yifecka s uksawen yesskan iɣewwaṛen n ufecku neɣ n yiferdisen yettwafernen, am yini n yizirig, ini n tačurt d tuzert.

Asebrureq d usenṭel

Suneɣ tamnaṭ n usebrureq (H) neɣ n usenṭel (O) am usrem, sakin fren askar deg ufeggag n yifecka:

  • Sebrureq aḍris yessini tamnaṭ am umerkab, Jerreḍ tamnaṭ yesseḍlam yerna yesdeɛmumuc ayen nniḍen akk, Tifesniwin n umumed yerra ayen nniḍen akk d amumed, Semɣeṛ yesmeɣṛ tamnaṭ.
  • Piksilizi neɣ Sdeɛmumec ffren awalen uffiren, ismawen, uṭṭunen n yimiḍanen neɣ udmawen.

Agzam

Fren afecku n ugzam (C) sakin suneɣ tamnaṭ ara teǧǧeḍ, Enter yesentem, Esc yesefsax. Sit tikkelt nniḍen ɣef C, neɣ seqdec Askar n useggem deg ufeggag n yifecka, akken ad tbeddleḍ askar:

  • Gzem s wudem ubdid neɣ Gzem s wudem aglawan yekkes yiwen n uḍeggal seg tugna yerna yesdukkul ayen d-yeqqimen, am wakken ad tekkseḍ talemmast tilemt n usebter aɣezfan. Leryuf n tgezmi yefren amek ara d-yettban usdukkel: d asrid, s zigzag, s yilmawen, yettwacerrṭen neɣ war asdukkel.
  • Aseggem awurman yekkes iri n yiwen n yini i yezzin i tugna.

Rnu tugniwin, ales aseqdec n yiferdisen

  • Zuɣer afaylu n tugna ɣer umaẓrag, neɣ senṭeḍ tugna s Ctrl + V. Ger asfaylu deg wumuɣ Taẓrigt yettarnu tuṭṭfa n usfaylu nniḍen yeldin.
  • Seqdec yiwen n yiferdisen ɣef aṭas n tuṭṭfiwin: Sekles tiɣawsiwin deg ufaylu deg wumuɣ Taɣawsa, d Sali-d tiɣawsiwin seg ufaylu ɣef tuṭṭfa d-iteddun.
  • Sekles d afaylu .greenshot akken ad qqimen akk iferdisen ttwaẓrigen, ad tkemmleḍ ticki.

Isurifen iwurmanen d yiserwasen

Iserwasen xeddmen s wudem awurman tiɣawsiwin s tuṭṭfiwin-ik, am urnu n yiri i yal tuṭṭfa, neɣ asekles d usali s yiwet n tikkelt. Ismenyifen iruraden > Isurifen iwurmanen deg wumuɣ n tignit yessermad neɣ yessens isurifen iheggan, Ugar… yeldi iɣewwaṛen-nsen deg iccer Iserwasen. Umuɣ Iserwasen n tignit yessekkar iserwasen-ik yerna yeldi Amsefrak n yiserwasen d Recipe Editor. Iserwasen ttasen-d s usiɣzef Recipe Editor.

Ismenyifen

Ldi ismenyifen s Ismenyifen... deg wumuɣ n tignit, neɣ s yiseɣwan-a.

  • Amatu: tutlayt, initen (aceɛlal, ubrik neɣ am Windows), teɣzi n tignit, Senker Greenshot di tnekra n Windows, tisura, apṛuksi d acḥal n tikkal ara yenadi Greenshot ɣef yileqman.
  • Tuṭṭfa: tuṭṭfa n tḥenccaṭ n tɣerdayt, ṣṣut n tkamiṛat, asemɣer, asgumed n ugdil, ilɣa, araǧu send tuṭṭfa, tiɣzi-ik yettwasbadun, tuṭṭfa tamyigawt n usfaylu d tutlayt n usentem n uḍris.
  • Tuffɣa: akaram d tneɣruft n yisem n ufaylu i usekles (sit ɣef ? i yimeḍqan, am ${YYYY}-${MM}-${DD} neɣ ${title}; \ deg tneɣruft yesnulfuy ikaramen), amasal n tugna d tɣara n JPEG.
  • Taniɣert n tuṭṭfa n ugdil: d acu ara yeḍrun deffir n tuṭṭfa, wali anida ara tedduṭ tuṭṭfa.
  • Amaẓrag: iccaren, teɣzi n usfaylu n umaẓrag, asteqsi ɣef usekles mi ara t-tmedleḍ, d teɣzi d yini n tugna tamaynut.
  • Tasaggazt: aserwes n tugna ɣer usebter, tuzzya neɣ asemmes, asiggez s yini, s umumed neɣ s yini yettwattin, d uḍar n usebter s uzemz d wakud.
  • Isiɣzaf: sermed, sens, sbadu isiɣzaf. Ibeddilen ad ddun deg usenker d-iteddun n Greenshot.
  • Amazzag: iɣewwaṛen i tegnatin tudmawanin, am tnarit n umeccaq, tuṭṭfa DirectX (tettwasra i yigdilen HDR), takatut d urured, d yimasalen n ɣef afus. Beddel-iten kan ma tessneḍ d acu xeddmen.

Greenshot yeskles iɣewwaṛen-is deg greenshot.ini, deg %APPDATA%\Greenshot (lqem amaziz yeǧǧa-t ɣer tama n Greenshot.exe). Ifuyla & Tawila deg Tallalt tudmawant yesskan anda yella.

Ma yella kra ur yeddi ara

Tallalt tudmawant yesenqad Greenshot yerna yessefrak tuget n wuguren. Ldi-t s Ɣef Greenshot deg wumuɣ n tignit, sakin Tallalt tudmawant, neɣ ddu srid ɣer tgezmi i ilaqen:

  • Print Screen ur yexdim acemma neɣ yeldi kra nniḍen: Inegzumen n unasiw & Imennuɣen yesskan ma yella OneDrive neɣ Snipping Tool yeṭṭef tasarut, yerna yerra-tt i Greenshot.
  • Ur tufiḍ ara tuṭṭfiwin-ik: Ifuyla & Tawila yesskan anda ten-yeskles Greenshot.
  • Anɣal ɣef afus ur yeddi ara: Asenqed n ɣef afus yettaf ahil i iḥebsen ɣef afus.
  • Greenshot yeɣli neɣ yexuṣ usiɣzef deffir n uleqqem: Taɣdemt n usebded yesenqad ifuyla yebdan.
  • Azen-d ugur: Nɣel talɣut n unagraw deg Anagraw & Ibenkan d tuccḍiwin deg uɣmis ad aɣ-ɛiwnen ad k-nɛiwen. Azen-d uguren ɣer github.com/greenshot/greenshot/issues.

Tebɣiḍ ad d-tefkeḍ afus?

Xemmem ɣef tikci

Nexdem aṭas ɣef Greenshot, akken ad d-nefk aseɣẓan yelhan, baṭel yerna d aɣbalu yeldin. Ma yella yerra-k tesfaydeḍ ugar, yesseḥraz-ak neɣ i tkebbanit-ik akud d yedrimen, neɣ tḥemmleḍ Greenshot kan: ttxil-k xemmem ad aɣ-tɛiwneḍ. Wali https://getgreenshot.org/support/ amek tzemreḍ ad d-tefkeḍ afus.

Ssiweḍ awal

Ma tḥemmleḍ Greenshot, ini-yas i yimeddukal d yimdukal-ik n uxeddim. Efk azal i Greenshot deg yismal n yiseɣẓanen neɣ err aseɣwen ɣer usebter-nneɣ agejdan seg ublug neɣ seg usmel-ik.
