We are pleased to announce **Greenshot 1.3.322**, released on October 8, 2026. You can download it from the [official download page](https://getgreenshot.org/downloads/). While we continue developing Greenshot 1.4 with additional features and stability improvements, we did not want 1.3 users to wait for fixes that were already ready. We have therefore carefully brought many improvements from the 1.4 development line back to 1.3 to make it more reliable. Versions 1.3.319 through 1.3.321 were intermediate builds, and their changes are included in this stable release.

Most of these improvements came from our community. A special thank you goes to [@Christian-Schulz](https://github.com/Christian-Schulz), [@danrhodes](https://github.com/danrhodes), and [@FF-Brown](https://github.com/FF-Brown), who invested a great deal of time and worked with other contributors on features and bug fixes. The maintainers would also be glad if you [starred Greenshot on GitHub](https://github.com/greenshot/greenshot).

## 🔒 Security Fixes

**We strongly recommend that all Greenshot 1.3 users update to version 1.3.322.** This release fixes several security issues:

- TLS certificate validation was disabled process-wide, potentially exposing OAuth tokens and uploads to connected services—including Imgur, Box, Dropbox, Flickr, Confluence, and Jira—to man-in-the-middle attacks. Thanks to [@sondt99](https://github.com/sondt99), [@lihnucs](https://github.com/lihnucs), and [@dungNHVhust](https://github.com/dungNHVhust) for reporting this issue. The related [GHSA-xvfg-wm9q-gp77](https://github.com/greenshot/greenshot/security/advisories/GHSA-xvfg-wm9q-gp77) and [GHSA-q4w7-9m8v-53fm](https://github.com/greenshot/greenshot/security/advisories/GHSA-q4w7-9m8v-53fm) security advisories are currently drafts and may not yet be publicly accessible.
- Manipulated `CF_DIBV5` clipboard data could cause an out-of-bounds read and denial of service. We thank [@hacker1984](https://github.com/hacker1984) for reporting this issue. The related [GHSA-4674-75g5-79mx](https://github.com/greenshot/greenshot/security/advisories/GHSA-4674-75g5-79mx) advisory is currently a draft and may not yet be publicly accessible.
- Opening a manipulated SVG file could cause a server-side request forgery. We thank [@Zenquiem](https://github.com/Zenquiem) for reporting this issue. The related [GHSA-mmr7-mfv6-wp78](https://github.com/greenshot/greenshot/security/advisories/GHSA-mmr7-mfv6-wp78) advisory is currently a draft and may not yet be publicly accessible.
- [@jklingen](https://github.com/jklingen) updated dependencies to address known vulnerabilities, including Inno Setup 6.2.2 for CVE-2025-15595 and log4net 3.3.0 for CVE-2026-40021.

## 🛠️ Reliability Improvements

Many of the fixes below were first developed for Greenshot 1.4 and have now been deliberately backported to 1.3, with credit retained for the contributors who made the original changes:

- [@danrhodes](https://github.com/danrhodes) fixed an editor crash on open (issue #925, [PR #1003](https://github.com/greenshot/greenshot/pull/1003)); improved saving to locked or inaccessible files (issue #946, [PR #986](https://github.com/greenshot/greenshot/pull/986)); fixed a crash when changing the icon size in settings (issue #1007, [PR #1010](https://github.com/greenshot/greenshot/pull/1010)); corrected CTRL behavior while scaling (issue #1055, [PR #1087](https://github.com/greenshot/greenshot/pull/1087)); fixed an error when creating a capture (issue #1021, [PR #1022](https://github.com/greenshot/greenshot/pull/1022)); kept line thickness within its valid range (issue #1142, [PR #1151](https://github.com/greenshot/greenshot/pull/1151)); fixed a race condition in editor layout updates (issue #1169, [PR #1210](https://github.com/greenshot/greenshot/pull/1210)); and fixed several region-capture crashes (issues #1153, #1019, and #1031, [PR #1154](https://github.com/greenshot/greenshot/pull/1154)).
- Robin Krom ([@Lakritzator](https://github.com/Lakritzator)) fixed the tray icon disappearing permanently in RemoteApp/RAIL sessions (issue #1324, [PR #1348](https://github.com/greenshot/greenshot/pull/1348)) and improved handling of the OneDrive hotkey setting (issue #1170).
- Christian Schulz ([@Christian-Schulz](https://github.com/Christian-Schulz)) fixed instability caused by disposing of a shared font when changing the icon size ([PR #981](https://github.com/greenshot/greenshot/pull/981)) and resolved inconsistencies when saving file formats ([PR #1024](https://github.com/greenshot/greenshot/pull/1024)).
- [@overlord](https://github.com/overlord) fixed several toast notification problems, including a cross-thread exception ([PR #1147](https://github.com/greenshot/greenshot/pull/1147)).

## 🖼️ Configurable Border Effect

[@weihongji](https://github.com/weihongji) added a setting in `Greenshot.ini` to configure the Border effect, giving you more control over the editor effect ([PR #730](https://github.com/greenshot/greenshot/pull/730)). This was their first contribution to Greenshot—welcome, and thank you!

## 🧹 Cleaner Installations and Smoother Upgrades

Robin Krom ([@Lakritzator](https://github.com/Lakritzator)) improved the installer cleanup so it removes additional leftover files from older Greenshot versions ([PR #1092](https://github.com/greenshot/greenshot/pull/1092)).

Christian Schulz ([@Christian-Schulz](https://github.com/Christian-Schulz)) made Greenshot 1.3 close automatically when the Greenshot 1.4 installer upgrades it through the Windows Restart Manager ([PR #1109](https://github.com/greenshot/greenshot/pull/1109)), preventing conflicts during the upgrade.
