We are pleased to announce the release of **Greenshot 1.3.319**, the latest stable update to the Greenshot 1.3 series. You can grab it right away from the [official download page](https://getgreenshot.org/downloads/). This release focuses on reliability, correcting an issue with HTTPS certificate validation and backporting a collection of stability fixes from the upcoming 1.4 series, while also adding a small but welcome customization option for the editor.

## 🔒 Corrected HTTPS Certificate Validation

We fixed an issue where Greenshot did not validate HTTPS certificates correctly when communicating over the network. Certificates presented by remote servers are now checked properly, so you can trust that secure connections made by Greenshot are actually secure.

## 🛠️ Reliability Backports

Building on the stability work we started in earlier 1.3 releases, we backported a further collection of fixes originally made for the 1.4 series. These improve the reliability of screen capturing, image handling, the built-in editor, and desktop notifications, resulting in fewer glitches and a smoother day-to-day experience.

## 🖼️ Configurable Border Effect

The Border effect in the editor's image effects now has a configurable setting in `Greenshot.ini`, giving users more control over how the border is applied when exporting or copying an image.

## 🧹 Cleaner Legacy Plugin Cleanup

We further improved the installer's handling of leftover files from older Greenshot versions, making sure outdated plugin files are cleaned up more thoroughly before the new version is installed.

## 🔄 Reliable Shutdown During 1.4 Installer Upgrades

Greenshot 1.3 now shuts down reliably when the 1.4 installer needs to upgrade it, preventing conflicts between the old and new versions during the upgrade process and making the transition to 1.4 smoother for everyone.

## Thank You

Many thanks to our contributors who made this release possible: [Robin Krom](https://github.com/greenshot/greenshot/pull/1122) for the collection of reliability backports (including the HTTPS certificate validation fix) and the improved installer cleanup, and [Christian Schulz](https://github.com/greenshot/greenshot/pull/1109) for making sure Greenshot 1.3 shuts down reliably when upgraded by the 1.4 installer.
