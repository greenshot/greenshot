We are pleased to announce the release of **Greenshot 1.3.319**, the latest stable update to the Greenshot 1.3 series. You can grab it right away from the [official download page](https://getgreenshot.org/downloads/). This release corrects a security issue in our HTTPS certificate validation and backports a large collection of stability fixes that were originally made for the upcoming 1.4 series, while also adding a small but welcome customization option for the editor.

## 🔒 Security Fix

We fixed a security issue where TLS certificate validation was disabled process-wide, which meant that OAuth tokens and uploads to connected services such as Imgur, Box, Dropbox, Flickr, Confluence, and Jira could potentially be exposed to a man-in-the-middle attack. We would like to thank [@sondt99](https://github.com/sondt99) and [@lihnucs](https://github.com/lihnucs) for reporting this issue. The public security advisory for this fix is still being finalized and will be linked here once it has been published.

## 🛠️ Reliability Backports

Many of the stability fixes originally developed for the 1.4 series have now been backported to 1.3, so that current users benefit from them as well:

- [@danrhodes](https://github.com/danrhodes) fixed a crash when opening the editor (issue #925, [PR #1003](https://github.com/greenshot/greenshot/pull/1003)), made saving to locked or otherwise inaccessible files more robust (issue #946, [PR #986](https://github.com/greenshot/greenshot/pull/986)), fixed a crash when changing the icon size in the settings (issue #1007, [PR #1010](https://github.com/greenshot/greenshot/pull/1010)), fixed CTRL not behaving as expected while scaling (issue #1055, [PR #1087](https://github.com/greenshot/greenshot/pull/1087)), fixed an error that could occur while creating a capture (issue #1021, [PR #1022](https://github.com/greenshot/greenshot/pull/1022)), fixed the line thickness being able to fall outside its valid range (issue #1142, [PR #1151](https://github.com/greenshot/greenshot/pull/1151)), fixed a race condition in editor layout updates (issue #1169, [PR #1210](https://github.com/greenshot/greenshot/pull/1210)), and fixed several crashes during region capture (issues #1153, #1019, #1031, [PR #1154](https://github.com/greenshot/greenshot/pull/1154)).
- Robin Krom ([@Lakritzator](https://github.com/Lakritzator)) fixed the tray icon permanently disappearing in RemoteApp/RAIL sessions (issue #1324, [PR #1348](https://github.com/greenshot/greenshot/pull/1348)) and improved the handling of the OneDrive hotkey setting (issue #1170).
- Christian Schulz ([@Christian-Schulz](https://github.com/Christian-Schulz)) fixed instability caused by disposing of a shared font when changing the icon size ([PR #981](https://github.com/greenshot/greenshot/pull/981)) and resolved inconsistencies when saving certain file formats ([PR #1024](https://github.com/greenshot/greenshot/pull/1024)).
- [@overlord](https://github.com/overlord) fixed several toast notification problems, including a cross-thread exception ([PR #1147](https://github.com/greenshot/greenshot/pull/1147)).

## 🖼️ Configurable Border Effect

[@weihongji](https://github.com/weihongji) added a configurable setting for the Border effect in `Greenshot.ini`, giving users more control over how the border is applied when exporting or copying an image ([PR #730](https://github.com/greenshot/greenshot/pull/730)) — their first contribution to Greenshot. Welcome, and thank you!

## 🧹 Cleaner Legacy Plugin Cleanup

Robin Krom ([@Lakritzator](https://github.com/Lakritzator)) improved the installer so that it removes additional leftover files from older Greenshot versions ([PR #1092](https://github.com/greenshot/greenshot/pull/1092)), giving users a cleaner installation.

## 🔄 Reliable Shutdown During 1.4 Installer Upgrades

Christian Schulz ([@Christian-Schulz](https://github.com/Christian-Schulz)) made Greenshot 1.3 close itself automatically when the Greenshot 1.4 installer needs to upgrade it via the Windows Restart Manager ([PR #1109](https://github.com/greenshot/greenshot/pull/1109)), avoiding conflicts between the old and new versions and making the transition to 1.4 smoother for everyone.

## Thank You

This release would not have been possible without the many contributors above, who took the time to backport fixes from the 1.4 development line to 1.3 or contribute new improvements directly. Thank you all!
