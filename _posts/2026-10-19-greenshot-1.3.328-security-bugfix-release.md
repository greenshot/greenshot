We’re pleased to announce **Greenshot 1.3.328**, a focused security and bug-fix update for the 1.3 series. Download it now from our [official download page](https://getgreenshot.org/downloads/).

## 🔒 Security Fixes

Earlier Greenshot 1.3 builds could send Windows NTLM/Negotiate credentials when requesting a URL on an untrusted host. This release stops attaching Windows credentials to requests sent directly to arbitrary servers, closing that path. Thanks to [@Y4k150b4](https://github.com/Y4k150b4) for reporting the issue and [@Lakritzator (Robin Krom)](https://github.com/Lakritzator) and [@jklingen](https://github.com/jklingen) for the fix ([release commit](https://github.com/greenshot/greenshot/commit/5b7dca10d9b56dc5fef55189030879a1ddd29312)). See the [GHSA-gjcr-pccx-w2vg security advisory](https://github.com/greenshot/greenshot/security/advisories/GHSA-gjcr-pccx-w2vg) for details.

## 🛠️ Improvements & Fixes

We also fixed a crash that could occur when Windows wouldn’t create the toast notifier. Greenshot now skips the unavailable notification and keeps running ([PR #1515](https://github.com/greenshot/greenshot/pull/1515)).

All shipped executables and DLLs are now signed, so Smart App Control no longer blocks them ([PR #1505](https://github.com/greenshot/greenshot/pull/1505), thanks to [@Lakritzator](https://github.com/Lakritzator) and [@jklingen](https://github.com/jklingen)).

## 🔮 What’s Next

This is a maintenance update for Greenshot 1.3 users while work on Greenshot 1.4 continues.
