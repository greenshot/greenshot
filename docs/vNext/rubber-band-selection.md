# Rubber-band selection

In selection mode, drag empty canvas to select fully enclosed objects. Shift-drag toggles those objects against the selection at drag start. Escape or lost mouse capture restores the original selection. Clicking empty space clears the selection; Shift-clicking empty space preserves it.

The four-screen-pixel drag threshold and the selection outline follow zoom. Selection changes do not modify drawing geometry or add undo entries. No groups, snapping, measurements or rotation changes are required.
