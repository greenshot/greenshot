Dynamic Scopes & Variables Cheat Sheet

Greenshot evaluates mathematical expressions, environment scopes, surface metrics, and format strings inside ${...} expressions across all recipe parameters.

Scope Prefix Description Examples (Click to copy)
user.* Windows User Environment Variables ${user.username} ${user.temp} ${user.appdata}
machine.* System-wide / Machine Environment ${machine.computername} ${machine.os}
payload.* Dynamic Capture Surface Dimensions ${payload.width} ${payload.height} ${payload.width - 200} ${payload.height * 0.5}

Greenshot DAG Recipe Guide
DAG Workflow Concepts
  • Nodes: Modular execution steps (e.g. Capture, Border, Watermark, Destinations).
  • Transitions: Directed connections between steps.
  • Forking (Parallel): Connect 1 node to multiple targets to run branches concurrently.
  • Joining (Merge): Connect multiple branches to a single downstream step to barrier-synchronize.
  • Acyclic Rule: Loops/cycles are automatically detected and forbidden.
Quick Tips
  • Drag from the bottom port of a box to the top port of another box to connect.
  • Click the red × button on any connection to delete it.
  • Hold spacebar or use middle click to pan the canvas.
  • Drop any .gsrecipe.json file straight into the browser to open it!
