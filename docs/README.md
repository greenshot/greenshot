# Greenshot documentation

The documentation is split by version, so nobody reads about a feature their Greenshot doesn't have:

- **This folder** describes Greenshot 1.3, the current release.
- **[vNext](vNext/README.md)** describes Greenshot 1.4, which is in development on the `main` branch. Everything there is new or
  works differently than in 1.3, and can still change before the release.

| Document | What it is about |
|---|---|
| [capture-user-guide.md](capture-user-guide.md) | Taking a screenshot with Greenshot 1.3: the capture modes, the keys and the settings |
| [release-management.md](release-management.md) | How releases are versioned, built and published |
| [changelogs](changelogs/README.md) | What changed in each release, 1.3 and the 1.4 development builds |

When a 1.4 feature is released, its document moves from `vNext` to this folder.
